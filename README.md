# מעבדה בתכנות מערכות - פרויקט אסמבלר (קורס 20465)

מאגר זה מכיל את פרויקט הסיום לקורס "מעבדה בתכנות מערכות" (20465) באוניברסיטה הפתוחה, סמסטר אביב 2024.

**ציון הפרויקט: 100** 🎉

## מגישים
- יונתן גפרי
- נחמיה רוזנברג

## על הפרויקט
פרויקט זה הוא אסמבלר מותאם אישית שנכתב בשפת C. האסמבלר קורא קבצי מקור בשפת סף (הכוללים שימוש במאקרו), מתרגם אותם לשפת מכונה, ומפיק את הקבצים המתאימים (קובץ אובייקט, קובץ כניסות וקובץ חיצוניים) בהתאם לארכיטקטורת המחשב הדמיוני כפי שהוגדרה בחוברת הקורס.

## תכונות עיקריות
- **פריסת מאקרו (Pre-assembler):** שלב מקדים שמזהה ופורס את פקודות המאקרו בקוד.
- **מעבר כפול (Two-Pass Assembly):** 
  - מעבר ראשון: בניית טבלת הסמלים ותמונת הנתונים.
  - מעבר שני: קידוד ההוראות ופענוח הסמלים.
- **טיפול בשגיאות:** בדיקה קפדנית של שגיאות תחביר וסמנטיקה תוך הצגת הודעות שגיאה מפורטות.
- **קבצי פלט:** יצירת קבצי `.ob` (אובייקט), `.ent` (כניסות), ו-`.ext` (חיצוניים) לאחר קימפול מוצלח.

## איך לקמפל ולהריץ
יש לוודא שמותקנים `gcc` ו-`make` על המחשב.

1. **קימפול:**
   השתמשו ב-`makefile` המצורף כדי לקמפל את הפרויקט.
   ```bash
   make
   ```
2. **הרצה:**
   העבירו את שמות קבצי האסמבלי (ללא סיומת `.as`) כארגומנטים.
   ```bash
   ./assembler file1 file2
   ```

## מבנה המאגר
- `source_code/`: מכיל את כל קבצי המקור (קוד ב-C).
- `header_files/`: מכיל את כל קבצי הכותרות (`.h`).
- `makefile`: קובץ לבניית הפרויקט.
- `tester*`: קבצי בדיקה שונים ששימשו לבדיקת האסמבלר.
